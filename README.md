# Ben Holden

Ben Holden is an environmental engineer. Outside work he does home automation,
AI projects and a lot of do-it-yourself projects. God, family and his kids are
at the center of all of it.

Most of my code is written with AI. My part is the spec, catching the model
when it is wrong, and checking that things actually ran. Write-ups are at
[benjaminmholden.com](https://benjaminmholden.com).

### Things I've built
Most run my house, so they live in private repos.

- **A picture book from a bedtime story**: a voice memo turned into a
  read-along book. Kit: [bedtime-storybook-kit](https://github.com/benjamin-m-holden/bedtime-storybook-kit)
- **A house that runs itself**: 112 automations across 488 devices in Home Assistant (October 2026)
- **Decades of family video, searchable**: prints and tapes digitised, transcribed, dated and georeferenced
- **A home server that checks its own work**: nightly backups, and a morning summary that flags anything that did not run
