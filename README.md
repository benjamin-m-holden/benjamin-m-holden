# Ben Holden

Ben Holden is an environmental engineer. Outside work he does home automation,
AI projects and a lot of do-it-yourself projects. God, family and his kids are
at the center of all of it.

Most of my code is written with AI. My part is the spec, catching the model
when it is wrong, and checking that things actually ran. Write-ups are at
[benjaminmholden.com](https://benjaminmholden.com).

### Things I've built
Most run my house, so they live in private repos.

- **A picture book from a bedtime story**: a forgotten voice memo turned into a
  read-along book. [Write-up](https://benjaminmholden.com/writing/picture-book/) ·
  Kit: [bedtime-storybook-kit](https://github.com/benjamin-m-holden/bedtime-storybook-kit)
- **A LEGO guide for a mixed-up set**: a phone guide that finds the bricks for
  each step after all 500 pieces got poured together. [Write-up](https://benjaminmholden.com/writing/lego-guide/)
- **A doorbell wiring mistake, caught by AI**: a two-second video of a buzzing
  chime, and the install error from a year and a half earlier. [Write-up](https://benjaminmholden.com/writing/reolink-doorbell-wiring-mistake/)
- **A house that runs itself**: 114 automations across 492 devices in Home Assistant (November 2026)
- **Decades of family video, searchable**: prints and tapes digitised, transcribed, dated and georeferenced
- **A home server that checks its own work**: nightly backups, and a morning summary that flags anything that did not run
